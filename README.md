## 🎯 What This Does

This project documents how to recognize and troubleshoot **keybind & input troubleshooting** in **S.O.N.A.R.**. It focuses on **Keyboard mapping, input conflicts and controller setup in submarine stations** with targeted checks, patch awareness, and reproducible testing so players can narrow down the actual cause instead of guessing.

## ✨ Features

- Checks duplicate key assignments at submarine stations.
- Isolates keyboard, mouse and gamepad conflicts by testing each input device separately.
- Provides a repeatable station-specific input test and reporting checklist.

## 🔎 Symptoms Covered

- A station control fails to respond to a mapped key.
- A keyboard shortcut conflicts with another binding.
- One player’s controls behave differently after changing devices.

## 🛠️ Troubleshooting — Step by Step

1. **Check the current bindings.** Open the game’s input settings and note the action and assigned key before editing.
2. **Remove duplicate assignments.** Check whether two actions are mapped to the same key.
3. **Compare devices.** Test with keyboard and mouse only, then reintroduce the gamepad if used.
4. **Test one station.** Repeat the same action at the same station after each change.
5. **Record reproducible failures.** Note game version, layout/language, input device and specific action that fails.

## ✅ Version & Patch Context

Control issues depend on build and input device; the checks do not assume that an automatic remapping tool exists.
